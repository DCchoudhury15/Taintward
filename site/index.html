How it works

The model gets placeholders. Your agent still works.

Masking everything to [PII] breaks the agent: it can no longer write to Alice about her tax form. Taintward swaps each value for a stable placeholder on the way to the LLM, and swaps the real value back on the way to your user or your own systems.

1 · your agent sends

Write to Alice Lee (alice@acme.com)
about the missing form for
SSN 234-12-1234.

2 · the LLM provider sees

Write to <PERSON_1> (<EMAIL_1>)
about the missing form for
SSN <SSN_1>.

The real values never leave your process.

3 · your user gets

Hi Alice Lee, we are still
missing one form for the account
ending in 1234...

An external API or a log line only ever gets a one-way mask.

Integration guide
you use MCP tools

MCP gateway

Put it in front of any MCP server. No code changes. Per tool: redact, block, or only record.

# gateway.yaml
upstreams:
  crm: { command: crm-mcp-server }
tools:
  - match: "crm.get_*"
    destination: internal
  - match: "*.send_*"
    destination: external
    mode: block

The decision

No LLM judge. A policy file you can read.

The sidecar collector evaluates this Rego policy on every span before it is stored. Hover a rule to see which tools it fires on in the breach run.

collector/policy/pii_egress.regoexcerpt
package taintward # Sinks where raw sensitive data must not land.sensitive_sinks := {"external", "llm", "log"}non_adequate_jurisdictions := {"us"} # Rule 1: sensitive data reaching an external / llm / log sink.violation contains {"rule": "pii_egress", ...} if {    input.sensitive == true    input.destination in sensitive_sinks} # Rule 2: PII to a non-adequate jurisdiction (GDPR Art. 44).transfer_violation contains {"rule": "transfer", ...} if {    has_class(input.classes, "pii")    input.jurisdiction in non_adequate_jurisdictions} # Always redact raw sensitive values from stored spans.redact if {    input.sensitive == true}

rule 1 Egress

Sensitive data headed to an LLM, an external API or a log is a violation.

ask_llmcall_external_apiwrite_log

rule 2 Cross-border transfer

PII sent to a non-adequate jurisdiction, the GDPR Art. 44 case. Fires on top of rule 1.

ask_llmcall_external_api

always Redact before storage

The pipeline

Six stages, all in real time.

Each stage replaces a piece of the AgentRaft research pipeline with something that runs live on OpenTelemetry.

Research to runtime

Built on research. AgentRaft measured the leak, Taintward stops it.

AgentRaft (Lin et al., 2026) found data over-exposure in 57% of the agent call chains it analyzed. Taintward keeps its formal model, D_OE = (D_trans \ (D_nec ∪ D_int)) ∩ D_total, and makes it enforceable.
