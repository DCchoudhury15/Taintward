A GPS tracker for sensitive data inside AI agents.

Agents chain tool calls: read a database, hand the result to an LLM, call an API, write a log. Somewhere in that chain an SSN or an API key slips out. AgentWard tracks where sensitive data actually goes, live, and redacts it before it leaves.

How it works

Six stages, each one running in real time with no LLM in the hot path.

01 / detect

Find the sensitive fields

Presidio plus secret patterns scan every tool's input and output as it passes through.

02 / propagate

Tag the call chain

A compact tag (taint.id, taint.classes, never the value) rides in OTel baggage to every downstream span. It survives even when an LLM rewrites the data.

03 / decide

Policy at the sink

A Rego policy in a sidecar collector decides: sensitive data headed to an LLM, an external API or a log is a violation. Cross-border PII is flagged too.

04 / redact

Context-aware redaction

Internal tools get a reversible token with the same shape. Anything leaving gets a one-way mask, before it is ever stored.

05 / record

Evidence you can verify

A tamper-evident Merkle log plus SigNoz dashboards for lineage, blast radius and SLOs, usable as GDPR Art. 30 records.

06 / recover

Suggest the fix

A fix suggester walks the agent's source code for unguarded sinks and proposes a one-line patch.

From research to runtime

AgentRaft (Lin et al., 2026) showed data over-exposure in 57% of the agent call chains it analyzed. AgentWard keeps its formal model and makes it run live on infrastructure you already have.

AgentRaftAgentWard
PropagationLLM-judged semantic dependencyOTel baggage and span links, real time, no LLM
"Was it necessary?"Vote of three LLMsDeterministic, auditable Rego policy
InputCustom benchmark trace formatStandard OTel gen_ai.* spans in SigNoz

Run it yourself

Unit tests run without anything else. The end-to-end demo needs SigNoz and the sidecar collector.

# unit tests
python3 -m unittest discover tests
cd collector/processor/taintpolicy && go test ./...
# end-to-end: start SigNoz and the sidecar collector, then
python3 demo/hr_bot/breach_simulator.py --endpoint http://localhost:4319/v1/traces
# open http://localhost:8080 and filter on agentward.violation=true
